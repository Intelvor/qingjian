云联想缺省关闭。打开后，输入拼音时会将当前拼音与光标附近的文字发送给**用户自行填写的** AI 服务商，换回候选词与整句补全。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

## 开启

「偏好设置 → 云服务」：打开开关，填写服务地址、模型、API 密钥。缺省为 DeepSeek，任何 OpenAI 兼容的服务均可。
密钥只保存在本机，不随配置文件导出。菜单栏「中 / 英」之后带 ☁︎ 表示联想已开启。
填写完成后点「测试连接」，将以当前地址、模型、密钥发送一条最小请求，结果显示在窗口底部：成功时显示模型名与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

**临时关掉**：Windows 的[悬浮状态条](../input/english-mode.md#悬浮状态条（Windows）)上有一格 ☁，点一下即可开 / 关在线联想（写回配置文件、立刻生效），想在某些场合不把文字发出去时用它；「云服务」页的开关是同一项。

发送的内容：所敲字母、本机的切分、**光标前最多 64 字、后最多 32 字的上下文**（「云服务」页的 `lookback` / `lookahead` 可改）、本机给出的候选。详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

输入拼音时停顿 300 毫秒后，云端给出的词补入候选第一页**末尾**两格（「云服务」页可调为 0 至 4），带云朵标记，数字键正常选择，上屏消耗整段拼音。

- 前面的本地候选位置不变，`Space` 上屏的仍是本地首选。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。

## 整句补全

同一次请求还返回一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧。
`Tab` 接受，继续输入则替换。**光标后面已有文字时，补全只填你敲的这段拼音缺的那几个字**（不会把后面已有的文字再补一遍）；
没有下文时才给一条完整的短句。

## 译词自动补充

随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），返回的译词存入本机的个人释义表，下次候选旁即有显示。
关闭云服务后不再发送任何请求。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。
