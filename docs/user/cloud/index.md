云联想缺省关闭。打开后，输入拼音时会将当前拼音与光标附近的文字发送给**用户自行填写的** AI 服务商，换回候选词与整句补全。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

## 开启

「偏好设置 → 云服务」：打开开关，填写服务地址、模型、API 密钥。缺省为 DeepSeek，任何 OpenAI 兼容的服务均可。
密钥只保存在本机，不随配置文件导出。菜单栏「中 / 英」之后带 ☁︎ 表示联想已开启。
填写完成后点「测试连接」，将以当前地址、模型、密钥发送一条最小请求，结果显示在窗口底部：成功时显示模型名与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

**临时关掉**：Windows 的[悬浮状态条](../input/english-mode.md#悬浮状态条（Windows）)上有一格 ☁，点一下即可开 / 关在线联想（写回配置文件、立刻生效），想在某些场合不把文字发出去时用它；「云服务」页的开关是同一项。

发送的内容：所敲字母、**光标前后的上下文**（缺省前 64 字、后 32 字；「云服务」页的「前文长度」「后文长度」可以调，0 表示不发那一边）、**候选窗口第一页已有的候选**（让模型别重复它们）、
以及当前的输入方式（全拼 / 双拼 / 大千注音 / 五笔）与是否繁体输出。发出的就是你敲的原始按键，**本机不做切分、纠错之类的加工**，由模型自己理解你想打什么（夹着英文词、敲错一两个字母都交给它）。
详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

输入拼音时停顿 300 毫秒后，云端给出的词补入候选第一页**末尾**两格（「云服务」页可调为 0 至 4），带云朵标记，数字键正常选择，上屏消耗整段拼音。
使用[双拼](../input/fuzzy-and-shuangpin.md)或[注音](../getting-started/keys.md#注音模式（Windows）)输入时云端联想照常工作：发出去的是解出来的读音，与全拼一致。

- 前面的本地候选位置不变，`Space` 上屏的仍是本地首选。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 与候选窗口第一页重复的云端词会被丢掉；返回的其他词**本机不再校验，直接进候选**。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。
- 中英混着输入时云端也认：敲 `linux` 可能得到 `Linux系统`，中文语境里的英文术语（Docker、API）同样会出现在云端候选里。
- 只敲声母（简拼，如 `fhyq`）时云端不再给词，只给整句补全——按声母凑出来的词大多不是真词。
- **敲到 20 个字母就不再要云端词**，只留整句补全：这么长的输入本来就是一整句话，逐个词联想没有意义。

## 整句补全

同一次请求还返回一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧。
`Tab` 接受，继续输入则替换。**光标后面已有文字时，补全只填你敲的这段拼音缺的那几个字**（不会把后面已有的文字再补一遍）；
没有下文时才给一条完整的短句。

整句**本机不再校验**：模型给什么就用什么（拼音切不开的输入也照样能补，例如敲 `javashiyimenbianchengyuyan` 能补出「Java 是一门编程语言」），
只丢掉与候选窗口第一页重复的、以及把光标后面那段话又写了一遍的。

整句里的数字按中文习惯写：金额、数量、序号写阿拉伯数字，口语量词与成语写汉字，
所以同一句话里两种会混着来——敲 `wohuayibaiershisanyuanmailesangempsan` 补出来是「我花123元买了三个mp3」，
不是「我花一百二十三元买了3个mp3」。

什么时候去要这条整句，在「云服务」页的「整句联想时机」里选：

- **停止输入后自动联想**（缺省）：与云端候选词同一次请求，停手 300 毫秒后自动取回。
- **按 Tab 键时才联想**：平时不问整句（云端候选词照常自动取回），按一下 `Tab` 才开始算，拼音右侧先出现 `☁ …`，算好了换成整句，再按一次 `Tab` 采用。想省用量、或不想每次停顿都去问一句时用它。

按 `Tab` 或点那块位置时若这次问不出去（云联想没开、或关了上面的「整句补全」），会在候选窗口里说明原因，不会悄无声息。

## 续写

没在打拼音时也能让云端接着写：敲一下**续写键**（缺省 `i`，双拼下是 `Shift` + `I` —— 那几套方案里 `i` 是音节键）再按 `Tab`，云端只看光标前后的文字，给出紧接着往下写的一小段，
显示方式与整句补全相同，再按一次 `Tab` 采用。敲 `i` 这个动作本身不会上屏。

- 光标前面没有文字（没什么可接的）时不发送。
- 光标后面已有文字时，续写只填中间那一小段，不会把后面的文字再写一遍。
- 续写键在「快捷键」页可改（与表达式键、问字键三个不能相同）。

## 译词自动补充

随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），返回的译词存入本机的个人释义表，下次候选旁即有显示。
关闭云服务后不再发送任何请求。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。
