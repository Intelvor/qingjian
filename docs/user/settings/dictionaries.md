## 随包词库

基础词库 8.7 万条，另有 11 本领域词库随包：法律、医学、地名、成语、诗词名句、IT、财经、饮食、动物、汽车、历史人物。
缺省只开启成语，其余在「偏好设置 → 词库」勾选。领域词库只影响「是否有这个词」，不改变整句转换的权重。

## 导入用户词库

「偏好设置 → 词库 → 导入词库…」，接受这几种格式：

- 青简 TSV（`.tsv` 或 `.txt`）：每行 `词<Tab>拼音<Tab>词频`，拼音音节间以空格分隔。
- Rime 的 `.dict.yaml`：读取名称和文件内的词条，词条须为 `词<Tab>拼音[<Tab>权重]`，拼音音节间以空格分隔，非整数权重按 1 处理。不支持 `import_tables` 引用的其他词库、自定义 `columns` 列顺序或 `.schema.yaml` 方案配置。
- 青简 `.qj`：他人制作的词库文件，自带名称与许可证。

TSV 与 Rime 词库导入时，`lue` / `nue` 自动统一为 `lve` / `nve`。词库用 `v` 表示 ü。
旧词库里写成 `lue` / `nue` 的词也照常能打。

导入后列在随包词库之下，显示名称、条数、许可证。可单独开关；「移除」只将文件移到一旁，不删除。

**也可以不导入，直接把文件放进词库目录**（Windows：`%APPDATA%\Qingjian\dicts`；macOS：数据目录下的 `dicts/`）：
`.qj` / `.tsv` / `.txt` / Rime 的 `.yaml` `.yml` 都会按内容识别并加载，与导入效果相同。同名的两个文件
（如 `law.qj` 与 `law.dict.yaml`）算同一本，优先用 `.qj`。后缀不在这一批里的文件加载不了，设置页会把它们列出来提示「导入词库…」转换。

Windows 导入时会转换成 `.qj` 并自动启用，设置页显示导入条数或失败原因。没有可用词条的文件不能导入。
文件选择窗口支持按 Ctrl 或 Shift 多选，批量导入 YAML、TSV、`.txt` 或 `.qj`；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入和移除也会自动更新，无需重启。
若手动编辑配置时出现格式错误，词库仍按上次有效的开关设置加载；修正配置后自动恢复应用新设置。

## 个人词

词库里没有、而你选中过的词（自己「造」的词、接受的云端词）会记成**个人词**，列在「偏好设置 → 词库 →
个人词」里，按词排序；词多的时候可以用上面的框按**词或拼音**筛。

点某一条的「删除」就忘掉它 —— 连它记下的选择次数、按输入串的选择、个人 n-gram 里跟它有关的痕迹一起清掉
（个人敲错表不动）。删完一秒内生效，刷新这一页就看不到它了。

**「个人词」与「导入的词库」是两回事**：导入的词库是你带进来的整本词表（文件级的开关 / 移除），
个人词是青简照着你的选择自己攒出来的。
